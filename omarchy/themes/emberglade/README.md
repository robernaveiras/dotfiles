# Emberglade for Omarchy

An original Omarchy theme: deep forest black-green surfaces, a burnished amber
accent, warm parchment text. Nature, forest, wood, autumn — elegant, dark,
high contrast.

Contrast (WCAG): foreground on background **12.0:1**, bright foreground
**14.8:1**, accent on background **6.8:1**, selection text **9.1:1**.

## Use

```bash
omarchy theme set emberglade
```

Backgrounds cycle with `Super + Ctrl + W`:

1. `1-fallen-leaves` — backlit gold leaf on a shadowed leaf carpet
2. `2-autumn-path` — sunlit canopy over a dark forest track
3. `3-pine-and-birch` — pine and birch columns, mossy floor
