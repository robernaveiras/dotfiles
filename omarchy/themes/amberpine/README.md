# Amberpine

Autumn forest at dusk: black-green timber, ember orange, bone light.
High-contrast dark palette inspired by nature — deep pine greens, warm oak browns,
burnt-orange accent, near-black backgrounds.

- Mode: dark, high contrast (near-black green backgrounds, bright bone foreground)
- Accent: burnt ember orange `#e07b36`
- Backgrounds: aerial autumn canopy (dark conifers + amber crowns, darkened for UI contrast); backlit misty forest with dim ember glow

Wallpapers: Unsplash (free Unsplash License) — Pascal Debrunner (misty forest), Royce Fonseca (canopy).
