# Emberwood

High-contrast forest-at-dusk theme: deep wood-black backgrounds, birch-cream
text, moss greens, and ember-orange accents. Warm wood tones replace every
blue slot — no blues anywhere in the palette.

- `colors.toml` — full semantic palette
- `backgrounds/` — four forest shots, warm-graded with ImageMagick
- `icons.theme` — Yaru-olive-dark
- `neovim.lua` — gruvbox (closest warm match to this palette)

Apply with: `omarchy theme set emberwood`
